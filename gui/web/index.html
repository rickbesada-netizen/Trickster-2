Timed plan

Each row sends a profile to a website for the time you set. Profile NO. is the number in the table (14, or a range like 3-5). Tick Scroll down to have the page scroll steadily to the bottom over that time. Click Actions to press a key (like the Down arrow) or type text at an exact second, for example "at 10 seconds, press Down arrow".
Several websites for one profile: use the same Profile NO. on more than one row. It visits them in order, in the same window, then closes.

Bulk assign proxies

      

        One line per proxy. Start a line with the profile's
        NO. (the number in the first column of the table) to
        send that proxy to it:

        14,isp.decodo.com:10001:user:pass — profile in row 14

        14-16,isp.decodo.com:10001:user:pass — rows 14 to 16, same proxy

        profile_014,... or a full name like
        profile_014_windows_desktop,... targets by file name instead.


        No number on a line = spread round-robin across every
        profile not targeted above.

        Proxy formats: host:port:user:pass,
        user:pass@host:port, http://host:port,user,pass.
        Lines that can't be matched are skipped and listed below — nothing is
        silently saved wrong.
